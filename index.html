Scratch 作品打包器

拖入 sb3，选择目标，得到可分享或安装的文件。全部计算在你自己的电脑上完成。
↓ 下载 Windows 版 从源码构建

四种产物

HTML
单个自包含 HTML
网页分享，快速测试
ZIP
HTML + 素材压缩包
上传到网站，后期继续编辑
EXE
单文件 EXE
发给 Windows 玩家即可运行
APK
已签名安卓 APK
安装到手机和平板

为什么好用

  • 原生离线 · 没有服务器、没有上传、没有登录
  • 一个工具四种产物 · HTML / ZIP / EXE / APK
  • 真正的批量模式 · 最多 20 个任务同时打包
  • 小体积 EXE · 额外体积约 0.9MB，图标/名称/版本可改
  • 不用安卓开发环境 · 包名、版本、方向、最低版本全可改
  • 轻量防解包 · 加密落盘，内存解密，运行不受影响
  • 老系统也能用 · 提供 Win7 SP1 的 32/64 位版本
  • 三档压缩预设 · 极速 / 标准 / 极限，一键切换

批量模式 · 每张卡片独立设置

运行参数
页面标题、舞台宽高、缩放模式、加速模式、帧率、补帧、高清画笔、无限克隆、边缘穿越

加载进度、加载文本、加载图片、窗口图标、自动开始

绿旗、停止、暂停、全屏，按需开关
队列管理

从源码构建

建议 Node 18 或更高
npm ci
npx cross-env NODE_ENV=production STANDALONE=1 VERSION=v2.5 webpack
node src/build/generate-standalone.js
启动器源码在 launcher，单文件启动器在 player，两者均为 C# WinForms + WebView2。
